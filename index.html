여기에 채점기준표 파일을 끌어다 놓거나 클릭해서 고르세요
PDF · 한글(hwp, hwpx) · 워드 · 파워포인트 · 엑셀/CSV · 사진·캡처 이미지 등 어떤 파일이든 됩니다. 캡처한 이미지는 이 화면에서 Ctrl+V로 바로 붙여넣어도 됩니다.
올리면 자동으로 읽어 체크리스트로 바꾸고 바로 적용합니다(확인 완료하지 않은 학생은 자동 재채점).

기준 보관함

보관함에 저장한 기준은 다른 과목·과제에서도 골라 쓸 수 있습니다. 같은 수업의 새 과제를 열면 그 수업에서 마지막으로 쓴 기준으로 시작합니다. "엑셀로 받기"한 파일을 고쳐서 다시 올리면 AI 없이 그대로 적용됩니다.

현재 채점 기준

평가 영역 점수 = 기본 점수(그 영역의 최저 수준) + 체크한 항목의 배점. 예) 기본 20 + 5점 체크 4개 → 20/25/30/35/40점. "자동 감지"에 키워드나 정규식을 넣으면 제출물 텍스트를 보고 미리 체크해 두고, 체크되지 않은 항목에는 "미충족 시 근거"가 채점 화면에 표시됩니다. 키워드·정규식을 고친 뒤에는 전체 자동 재채점을 눌러 주세요. 최종 판단은 선생님이 해 주세요.

AI 설정 (채점 기준 파일 읽기용)

PDF·한글·이미지 등 표 형식이 아닌 채점기준표는 구글 Gemini가 읽어서 체크리스트로 바꿉니다. 키는 Google AI Studio에서 무료로 만들 수 있고, 이 브라우저에만 저장됩니다(서버·저장소로 보내지 않음). 엑셀/CSV/JSON 기준 파일은 키 없이도 됩니다.

AI 채점 (Claude)

키워드·정규식 자동 감지 대신, Claude가 제출물을 직접 읽고 채점 체크리스트를 판단합니다 — class 없이 짠 코드인지, 표 빈칸을 안 채운 건지, 코드 로직이 실제로 맞는지까지 더 정확하게 봅니다. 왼쪽에서 학생을 선택한 뒤 채점 화면의 "🤖 Claude로 채점" 버튼을 누르세요(전체 학생 일괄 채점도 가능). 실제 API 요금이 청구되니 확인 완료된 학생에게는 자동으로 실행되지 않습니다. 키는 Anthropic Console에서 만들 수 있고, 이 브라우저에만 저장됩니다.
