# 클래스룸 수행평가 채점 도우미 (웹앱판)

🔗 **https://yongdeuk.github.io/classroom-grading-webapp/** (배포된 주소 — 학교(genedu.kr) 계정으로만 로그인 가능)

- 저장소: https://github.com/yongdeuk/classroom-grading-webapp (공개 저장소지만, 코드에는 학생 정보가 전혀 들어있지 않습니다.
  실제 데이터는 로그인한 사람의 브라우저가 그때그때 구글 API에서 가져와 그 브라우저에만 남습니다.)

구글 클래스룸의 제출물을 불러와 **루브릭에 따라 자동 채점 초안을 만들고, 교사가 화면에서 확인·수정**한 뒤,
제출 파일을 **미리보기·다운로드**할 수 있는 독립 웹앱입니다. 서버 없이 브라우저에서만 동작하며
(정적 파일 3종 + JS), 구글 클래스룸·드라이브는 **읽기 전용**으로만 접근합니다.

> `../grader/`(Apps Script + 스프레드시트 버전)의 뒤를 잇는 버전입니다. Apps Script 버전은 학교
> Workspace 정책상 문서/프레젠테이션 관련 민감한 권한 재동의가 막혀 있어 코드 추출이 불안정했는데,
> 이 웹앱은 Drive API를 브라우저에서 직접 호출해 그 문제를 피합니다.

## 왜 서버가 없나요?

Google Identity Services(GIS)의 브라우저 OAuth 흐름으로 로그인해서 얻은 접근 토큰으로
Classroom API·Drive API를 fetch로 직접 호출합니다. 채점 결과는 **이 브라우저의 localStorage**에
저장됩니다 — 즉 다른 컴퓨터·다른 브라우저에서는 안 보입니다. 정기적으로 상단의 **"백업(JSON)"**
버튼으로 저장해 두세요. (다른 컴퓨터와 공유하려면 CSV 내보내기를 쓰세요.)

## 설치 (Google Cloud Console, 처음 한 번만)

1. https://console.cloud.google.com 에서 새 프로젝트를 만듭니다 (학교 계정으로 로그인).
2. **API 및 서비스 → 라이브러리**에서 다음 2개를 검색해 각각 **사용 설정**합니다.
   - Google Classroom API
   - Google Drive API
3. **API 및 서비스 → OAuth 동의 화면**
   - User Type: **내부(Internal)** — 학교 Workspace 계정이면 이 옵션이 보입니다. 내부로 설정하면
     구글의 앱 검토 절차 없이 바로 쓸 수 있습니다(같은 학교 도메인 계정만 로그인 가능).
   - 앱 이름, 지원 이메일 등 최소 정보만 입력하고 저장합니다.
4. **API 및 서비스 → 사용자 인증 정보 → + 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: **웹 애플리케이션**
   - **승인된 자바스크립트 원본**에 이 앱을 여는 주소를 추가합니다.
     - 로컬에서 테스트: `http://localhost:8000` (아래 실행 방법의 포트와 맞추기)
     - 실제 배포 후: 배포한 주소 (예: `https://your-domain.vercel.app`)
   - 만들어진 **클라이언트 ID**(`...apps.googleusercontent.com`)를 복사합니다.
5. [`js/config.js`](js/config.js) 를 열어 `CLIENT_ID` 값을 방금 복사한 값으로 바꿉니다.

## 실행 방법

정적 파일이라 아무 웹 서버로나 열면 됩니다(파일을 `file://`로 직접 열면 CORS 문제로 안 됩니다 — 반드시
`http://`로 열어야 합니다).

```bash
cd webapp
python3 -m http.server 8000
```

그리고 브라우저에서 `http://localhost:8000` 을 엽니다.

배포할 때는 이 폴더(`webapp/`) 전체를 정적 호스팅(예: GitHub Pages, Vercel, Netlify)에 올리고,
그 주소를 3번의 "승인된 자바스크립트 원본"에 추가하면 됩니다.

## 사용 순서

1. **Google로 로그인** (학교 계정)
2. 수업·과제 선택 → **제출물 불러오기**
3. 잠시 기다리면 학생별로 제출 파일에서 텍스트를 자동으로 뽑고, 채점 기준에 맞춰 자동 채점 초안이 채워집니다.
4. 왼쪽 학생 목록에서 한 명씩 클릭 → 오른쪽에서 제출 파일 **열기/다운로드**, 추출된 텍스트, 항목별 점수와
   자동채점 근거를 확인·수정합니다. **확인 완료** 체크박스를 누르면 그 학생은 "전체 자동 재채점"을 눌러도
   점수가 바뀌지 않습니다.
5. 다 끝나면 **CSV 내보내기**(성적 처리용)와 **백업(JSON)**을 받아 둡니다.

## 채점 기준(루브릭) 수정

상단 "채점 기준(루브릭)" 표에서 항목·배점·유형·패턴을 직접 고칠 수 있습니다.

| 유형 | 동작 |
|---|---|
| 수동 | 교사가 점수를 직접 입력 |
| 키워드 | 패턴(쉼표로 구분) 중 제출물에 포함된 비율 × 배점 (0.5점 단위) |
| 정규식 | 패턴이 일치하면 만점, 아니면 0점 |
| 자동:설계 / 자동:구현 / 자동:예외 | "함수를 활용한 스택·큐 프로그램 구현" 수행평가 채점기준표 전용 수준 판정(추정) |

기본값은 배점 40/30/30(기본점수 40점)인 1차 수행평가 채점기준표 기준입니다. 항목을 바꾼 뒤
**"전체 자동 재채점"**을 누르면 확인 완료되지 않은 학생만 다시 채점합니다.

## 지원하는 파일 형식

| 형식 | 방법 |
|---|---|
| 구글 문서·슬라이드·시트 | Drive API로 텍스트/CSV 내보내기 |
| .py .txt .md .json .ipynb 등 텍스트 | 직접 읽음 |
| .docx | mammoth.js로 텍스트 추출 |
| .pptx | 압축을 풀어 슬라이드 텍스트 추출 |
| .hwpx | 압축을 풀어 본문 추출 |
| .pdf | pdf.js로 텍스트 추출 (스캔 이미지 PDF는 텍스트가 없어 실패 → 직접 확인) |
| 이미지, 구형 .hwp | 지원하지 않음 — "다운로드"로 직접 열어 확인 |

## 한계

- **자동 채점은 초안입니다.** 코드에 특정 패턴(키워드, `def push` 등)이 있는지만 보고, 실제로 동작하는지는
  확인하지 못합니다. 최종 점수는 교사가 확인 후 확정해 주세요.
- 채점 데이터는 **이 브라우저에만** 저장됩니다. 다른 기기에서 이어서 하려면 **백업(JSON)**으로 내보낸 뒤
  다른 기기에서 같은 수업·과제를 불러온 상태에서 **가져오기(JSON)**로 불러오면 됩니다.
- 새로고침하면 로그인이 풀립니다(토큰을 메모리에만 두기 때문). 다시 로그인하면 저장된 채점 데이터는
  그대로 남아 있습니다.
